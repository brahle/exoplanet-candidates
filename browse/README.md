# Browse signals

Dossiers keep stable paths. These folders are generated views of two independent axes: **work performed** and **scientific assessment**. Warnings and novelty are separate.

A completed diagnostic calculation is not a qualified scientific pass. “No initial warnings” does not mean “likely planet.”
