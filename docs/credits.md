# Credits and reuse

Bruno Rahle prepared these independent signal dossiers using TESS observations and publicly
available stellar/catalogue resources. Detection and vetting records distinguish original
analysis from mission reductions and previously reported signals. AI assistance was used for
code, documentation and audit bookkeeping; the published scientific claims remain subject to
human scientific review. No AI system is listed as an author.

TESS observations are credited to NASA's TESS mission; reductions to SPOC, TESS-SPOC and
the MIT Quick-Look Pipeline as identified in each input record. Data are distributed through
MAST. Catalogue stellar estimates come from the TESS Input Catalog and ESA Gaia/DPAC DR3,
including FLAME where stated. Consult the [TESS MAST data page](https://archive.stsci.edu/missions-and-data/tess)
and [Gaia credit instructions](https://www.cosmos.esa.int/web/gaia/credits) for formal papers
and acknowledgements appropriate to the specific products.

The catalogue check uses ExoFOP (DOI [10.26134/ExoFOP5](https://doi.org/10.26134/ExoFOP5)),
operated by Caltech under contract with NASA's Exoplanet Exploration Program, and the
[NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/).
This draft includes target query outcomes and derived scientific results. It does not assert
ownership over mission/catalogue data or transfer their original terms to the repository license.

The original analysis uses Astropy, SciPy, NumPy, Lightkurve and Wōtan; library versions and
formal software citations belong in the numerical reproduction capsule. Existing repository
code/documentation are MIT-licensed. Reusers should cite the exact candidate release/DOI,
its author and the underlying data/software. A missing DOI must not be replaced with a fabricated one.
